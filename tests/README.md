# Проверки сайта

Эти проверки запускают сайт в настоящем браузере (Chromium) на подставной базе (эмулятор Firebase), входят под владельцем, админом, флористом, оператором и посетителем и нажимают кнопки. Боевая база не затрагивается.

## Что нужно один раз
```
cd tests
npm init -y
npm i firebase@12.19.0 playwright firebase-tools
npx playwright install chromium
```

## Запуск
1. В корне репозитория поднять эмуляторы (правила берутся из `firestore.rules`):
   ```
   npx --prefix tests firebase emulators:start --only firestore,auth,storage --project mirflowersbase
   ```
2. В другом окне:
   ```
   node tests/site.cjs
   ```
   В конце строки `OK` и `FAIL`, затем `ERRS 0` (ошибок в консоли браузера нет). Скриншоты ложатся в `tests/out/`.
3. Обход всего сайта (каждая роль, телефон и ноутбук, все разделы и подразделы настроек): `node tests/walk.cjs`. В конце «OK пустых экранов…» или строки `FAIL` с адресом экрана; скриншоты лежат в `tests/out/walk/`. Запускать на чистых эмуляторах.
4. Страница продажи: `node tests/sell.cjs` (телефон и ноутбук, язык, картинки, бирка заказа; эмуляторы не нужны). Свежие снимки экранов для неё: `node tests/shots.cjs` (на чистых эмуляторах), результат в `tests/out/shots/`.
5. Проверка поиска без браузера: `node tests/search.test.js` (в конце `ошибок: 0`).

## Что проверяется
Витрина (настройка, публикация, права, страница клиента на телефоне и ноутбуке), страница статуса заказа, сообщения клиентам (настройки), права владельца, админа, флориста, оператора и посетителя в правилах базы, доступ сотрудникам, умный поиск в заказах и общем поиске.

## Чего здесь нет
Проверки облачных функций (сообщения «готов», «курьер выехал», отзыв) требуют эмулятора функций и имитации Evolution API. Они прогонялись отдельно, в репозиторий пока не вынесены.

## Аудит (стенд с функциями)
Подробно — `docs/audit/PHASE0.md`. Коротко:
```
npm ci --prefix functions
env -u HTTPS_PROXY -u https_proxy npx --prefix tests firebase emulators:start --only firestore,auth,storage,functions --project mirflowersbase
node tests/seed.cjs      # 2 точки, 10 сотрудников (пароль secret12), 300 заказов, 80 позиций, 60 чатов, «плохие» данные
node tests/sitemap.cjs   # карта сайта по ролям → tests/out/audit/sitemap.json
```
Общие помощники для проверок — `tests/audit-lib.cjs` (вход под ролью, размер, тема, язык, дизайн, ошибки консоли, вёрстка).
