# Аудит: найденные ошибки

Стенд: эмуляторы Firestore, Auth, Storage, Functions + тестовая база `tests/seed.cjs`
(300 заказов, 80 позиций склада, 60 чатов, плохие данные). Проверки:

- `node tests/audit-walk.cjs <дизайн> [роли] [размеры] [тема] [язык]` — обход всех разделов по ролям;
- `node tests/audit-flow.cjs` — сквозные сценарии (заказ → сборка → приёмка → оплата → выдача,
  доставка курьером, отмена через запрос, права помощника, страница клиента).

Приоритеты: **P0** — ломает работу или теряет данные; **P1** — важная функция работает неправильно;
**P2** — неудобно или выглядит сломанным; **P3** — мелочи.

## Сценарии (последний прогон)

Проходят: создание заказа (двойное нажатие — один заказ), сборка флористом с фото, приёмка, оплата
(«Принять без чека»), выдача, журнал действий, ссылка клиенту, доставка курьером (взял → еду → доставлено
с фото), отмена оператором через запрос и разрешение админа, права помощника, страница клиента `status.html`.
